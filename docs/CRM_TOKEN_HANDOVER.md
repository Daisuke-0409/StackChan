# CRMトークンを会社から家へ運ぶ (R6 の最後の1歩)

2026-08-19 作成。**明日の朝、会社でやること。所要2分。**

## なぜ必要か

同じ1つの合言葉を、2台のPCが持つ必要がある。

```
家のゲートウェイ  --(Tailscale)-->  会社の照会役  --(localhost)-->  CRM
   CRM_RELAY_TOKEN を送る            CRM_RELAY_TOKEN で確かめる
   ← 家はまだ空                      ← 会社には入っている
```

会社側は8/19に設定済み。**家側だけが空**なので、今は聞いても
「台帳の鍵が合わなかったよ」と返ってくる。

値をチャットに貼ったりメモ帳に書いたりしないこと。7/28 に Gmail の
アプリパスワードを画面表示で漏らした前例がある。**画面に出さないまま運ぶ**
仕組みを用意した。

## 会社PCで (朝いち)

```powershell
cd C:\Users\...\StackChan
powershell -File gateway\setup_crm_token.ps1
```

- CRM の config.json から読み直して `.env.crm_relay` に書き直すだけ
  (すでに入っているので実質は確認)
- **最後に出る `fingerprint: xxxxxxxx` の8文字だけメモする。**
  これは指紋であって鍵ではないので、写真に撮っても人に見せても安全
- 鍵そのものは `gateway\.env.crm_relay` の `CRM_RELAY_TOKEN=` の行にある。
  この行を見て、家で打ち込むために覚える (または安全な手段で運ぶ)

## 家PCで (帰宅後)

```powershell
cd C:\Users\mylit\StackChanDev\StackChan
powershell -File firmware\gateway\setup_crm_relay_token.ps1
```

- 入力欄は伏せ字。打った値は画面に出ない
- 最後に出る fingerprint が**会社でメモした8文字と一致すれば成功**
- ゲートウェイを再起動:
  ```powershell
  schtasks /run /tn "Tachikoma Gateway"
  ```

## 確認

タチコマに聞く:

> 田中さんの墓所どこ？

| 返事 | 意味 |
|---|---|
| 「〜地区の〜」「〜件あるよ」「見つからなかったよ」 | **成功** |
| 「台帳の鍵が合わなかったよ」 | 指紋が食い違っている。打ち間違い |
| 「会社のパソコンに繋がらなくて」 | 会社PCが落ちている (営業時間外は正常) |

## 覚えておくこと

- **会社PCが起動していないと引けない。**営業時間の機能。NAS移設で解消する
- 引けるのは4項目だけ (名前・霊園名+区画・地区・地図番号)。
  住所も故人名も受注日も**家には送られてこない**
- **読み取り専用。**書き込みAPIは存在しない
- 照会の内容も答えもタチコマの記憶には残らない。記録は CRM の audit_log 側
