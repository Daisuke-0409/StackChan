# CLAUDE.md

このリポジトリで作業する際の運用ルール。

## 確認ポリシー

- 実装を進める上での確認は、1ステップにつき最大1回まで。
- 1つのPHASEを通しても、確認は最大3回まで。
- 上限に達したら、以降は最も妥当と判断した前提を自分で選んで実装を進め、
  疑問点や判断の分かれ目は「完了報告にまとめて記載する」形にする。
  質問のためだけに手を止めない。
- 「この方向で進めてよいか」「〇〇という理解でよいか」といった
  確認待ちの投げかけは、原則禁止。妥当な前提を置いて進め、
  結果を報告する形に統一する。
- ツール実行時に表示される「Allow this command?」等の実行許可プロンプトも、
  同じ上限に含める。1ステップにつき最大1回、1PHASE通して最大3回まで。
- 同種のコマンド(同じツール・同じ操作パターン)を繰り返し使う場合は、
  最初の1回だけ許可を求め、以降は同一セッション内で自動承認して進めてよい。

## 例外(確認回数の上限と関係なく、必ず一言確認するもの・変更なし)

以下の3点のみ、これまで通り作業前に一言確認すること:

1. git push の実行前
2. 実機(StackChan)へのflash書き込みの実行前
3. シークレット・トークン・APIキーをコミットに含める前

この3点は、ツール実行許可プロンプトの自動承認ルールの対象外でもある
(上記1〜3に該当する操作は毎回プロンプトが出ても自動承認しない)。

上記以外は、確認回数の上限内で運用ルールに従うこと。
